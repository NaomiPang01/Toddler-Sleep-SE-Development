# 睡得好，社會情緒更穩定？
## 探討 36 月齡幼兒的睡眠與社會情緒發展的關聯 (2025 資料科學漫步 / 統計諮詢期末報告)

**作者：** 潘皓心、葉詠馨、黃芯鈺  
**資料來源：** 中央研究院社會科學資料庫（SRDA）— 臺灣幼兒發展調查資料庫建置計畫（KIT）：3月齡組第六波（36月齡）

---

## 📋 專案簡介 (Project Overview)
幼兒早期的睡眠健康是影響大腦發育與社會情緒能力的關鍵基石[cite: 296]。本研究基於全國代表性樣本（有效樣本 $N = 6,496$），針對 36 月齡幼兒的多面向睡眠模式（總體睡眠時數、睡眠規律性、主觀睡眠品質、半夜哭鬧頻率）與 13 項社會情緒發展構念之間的結構性關聯進行系統性檢驗[cite: 295, 297, 298, 299]。

與過往研究不同，本專案在模型中嚴格納入了**家庭環境與親職教養因素**（教養羞愧感、父母回應性、母親親職參與度）及人口學變項作為控制變項，並結合**多變量變異數分析（MANOVA / MANCOVA）**、**典型相關分析（CCA）**與**結構方程模型（SEM）**，驗證睡眠對幼兒社會情緒發展的獨立預測效應[cite: 295, 296, 298, 299, 300]。

---

## 📂 資料與變數架構 (Data & Variables)
* **原始樣本**：6,651 筆 36 月齡幼兒問卷資料[cite: 296]。
* **前處理與信度篩選**：針對反向題進行重新編碼，篩選 Cronbach's $\alpha \ge 0.60$ 之高信度構念，並以整筆刪除法（Listwise deletion）處理缺失值，最終保留 **6,496 筆**完整有效樣本（佔原始樣本 97.67%）[cite: 285, 296, 297, 304]。

| 變項類別 | 包含指標 |
| :--- | :--- |
| **自變項 (X) 睡眠模式** | 總體睡眠時數（小時）、睡眠規律性（規律/不規律）、主觀睡眠品質（1–4分）、半夜哭鬧頻率（1–4分）[cite: 298, 299] |
| **依變項 (Y) 社會情緒發展** | 奮力控制氣質、負向情緒性氣質、情緒表達、情緒理解、情緒調節、獨立性、主動性、合群性、順從性、退縮行為、攻擊行為、害羞、恥感（共 13 項構念）[cite: 298, 299] |
| **控制變項 (C) 背景與教養** | 幼兒性別、實際月齡、教養羞愧感、父母回應性、母親親職參與度[cite: 298, 299] |
